# Products

Each directory here is one product ownership boundary. Its applications,
installable product packages, release map, and product-specific operating
instructions stay together.

## Connection Hub

[`connection-hub/`](connection-hub/README.md) contains the Connection Hub
KDCube application and the reusable `connection-hub` Python distribution.
Public documentation remains in
[`docs/connection-hub`](../docs/connection-hub/README.md), and runnable
integrations remain in
[`examples/connection-hub`](../examples/connection-hub/README.md).
